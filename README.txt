ADWAITH T S — PORTFOLIO WEBSITE
================================

FILES
- index.html  Main website structure and content
- style.css   Dark premium styling, responsive layout and animations
- script.js   Mobile menu, scroll reveal, rotating hero text and email form

HOW TO RUN
1. Extract this ZIP file.
2. Keep index.html, style.css and script.js in the same folder.
3. Double-click index.html to open it in your browser.
4. For editing, open the folder in VS Code.

CUSTOMISE
- Edit your text, links and project descriptions in index.html.
- Change colours, spacing and layout in style.css.
- Change interactive behaviour in script.js.

CONTACT FORM NOTE
The form currently opens the visitor's default email application with a pre-filled message addressed to adwaithtsschool@gmail.com.
It does not send messages directly from the website. To receive submissions without the visitor's email app, connect a form backend/service or build a server-side endpoint.
